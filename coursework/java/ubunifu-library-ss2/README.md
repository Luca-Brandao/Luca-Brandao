# Ubunifu Library: Foundations

A Java console application covering book and user classes, encapsulation, arrays, borrowing, and a menu for adding, removing and displaying books.

**Module:** OOP152 SS2 · STADIO Higher Education

## Run locally

With a JDK installed, from this folder:

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out LibraryManagementSystem
```

## About this version

This is a portfolio copy of my academic submission. The coursework logic is retained; notebook outputs and local IDE/build files have been removed, and demo contact details and sample names have been standardised. Assignment PDFs and presentation video are kept outside this source repository.
