# Ubunifu Library: Extended System

An extended Java console application with ArrayList collections, a Librarian subclass, book and user searches, borrowing and returns.

**Module:** OOP152 SS3 · STADIO Higher Education

## Run locally

With a JDK installed, from this folder:

```sh
mkdir out
javac -encoding UTF-8 -d out src/*.java
java -cp out Main
```
