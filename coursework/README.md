# Academic Projects

Seven submissions from my Bachelor of Business Information Systems at STADIO. These show my progression from Python and Java fundamentals to an interactive web application.

| Project | Coursework | What it covers |
| :--- | :--- | :--- |
| [African History Quiz](python/african-history-quiz) | CTIP152 SS2 | A console quiz using randomised questions and answers, input validation, categories and score tracking. |
| [Savanna Ecosystem Simulation](python/savanna-ecosystem) | CTIP152 SS3 | A stochastic simulation of six savanna species over 50 years, modelling births, mortality, migration, ageing, drought, famine and baby booms. Results are written to a text report. |
| [Ubunifu Library: Foundations](java/ubunifu-library-ss2) | OOP152 SS2 | A Java console application covering book and user classes, encapsulation, arrays, borrowing, and a menu for adding, removing and displaying books. |
| [Ubunifu Library: Extended System](java/ubunifu-library-ss3) | OOP152 SS3 | An extended Java console application with ArrayList collections, a Librarian subclass, book and user searches, borrowing and returns. |
| [Online IT Courses: Static Website](web/cerebrum-ss1) | WST262 SS1 | A four-page online-course website built with HTML and CSS, with course listings, navigation, a team page and a contact form. |
| [Online IT Courses: Interactive Website](web/cerebrum-ss2) | WST262 SS2 | The next stage of the online-course website, adding JavaScript to the HTML and CSS site. |
| [Cerebrum Online IT Courses](web/cerebrum-ss3) | WST262 SS3 | A course platform with a Bootstrap frontend, Flask course and contact APIs, an Express testimonial API and JSON file storage. |

Each folder has its own setup instructions. Earlier stages remain separate so that the progression is visible. These are coursework demonstrations, with the original logic and any known limitations documented in the individual READMEs.
