# African History Quiz

A console quiz using randomised questions and answers, input validation, categories and score tracking.

**Module:** CTIP152 SS2 · STADIO Higher Education

## Run locally

Open `quiz.ipynb` in Jupyter and run the cells in order, or run the exported script:

```sh
python quiz.py
```

## About this version

This is a portfolio copy of my academic submission. The coursework logic is retained; notebook outputs and local IDE/build files have been removed, and demo contact details and sample names have been standardised. Assignment PDFs and presentation video are kept outside this source repository.

The original question bank is retained. One item stores “Mbira or Kalimba” as its answer while offering “Mbira”, so that item can mark a displayed correct choice as wrong.
