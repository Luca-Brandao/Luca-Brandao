# Savanna Ecosystem Simulation

A stochastic simulation of six savanna species over 50 years, modelling births, mortality, migration, ageing, drought, famine and baby booms. Results are written to a text report.

**Module:** CTIP152 SS3 · STADIO Higher Education

## Run locally

Open `simulation.ipynb` in Jupyter and run the cells in order, or run the exported script:

```sh
python simulation.py
```

## About this version

This is a portfolio copy of my academic submission. The coursework logic is retained; notebook outputs and local IDE/build files have been removed, and demo contact details and sample names have been standardised. Assignment PDFs and presentation video are kept outside this source repository.

The notebook and exported script are the main entry points. The standalone `dynamics.py` exercise assumes the population settings are already defined and is not a self-contained module. Random runs can produce different results.
