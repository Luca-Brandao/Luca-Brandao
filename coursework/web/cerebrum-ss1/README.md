# Online IT Courses: Static Website

A four-page online-course website built with HTML and CSS, with course listings, navigation, a team page and a contact form.

**Module:** WST262 SS1 · STADIO Higher Education

## Run locally

Open `Html/home.html` in your browser. Keep the `Html`, `Css` and `Images` folders together. This stage is a frontend coursework exercise.

This is a portfolio copy of my academic submission. The coursework logic is retained; notebook outputs and local IDE/build files have been removed, and demo contact details and sample names have been standardised. Assignment PDFs and presentation video are kept outside this source repository.
